Enterprise MVC Features

Designed according to academic Project-Based Learning curriculum requirements.

Automated Circulation Engine

Validates student borrow limit (4 books) and faculty limit (8 books). Auto-calculates return dates (14 days for students, 30 days for faculty).

Overdue & Fine Calculation

Automatic ₹5.00/day penalty algorithm for late returns with transparent multi-mode payment tracking (UPI, Cash, Card, Waiver).

FIFO Waitlist Queue

First-Come, First-Served queue for high-demand titles. Automatically assigns rank and notifies patrons when books are returned.

Live Analytics Visualizations

4 dynamic Chart.js dashboards: Stock distribution, Category breakdowns, 6-Month circulation trend, and Fine collection audit.

One-Click CSV Export

Generate real-time audit reports and export complete datasets for Books, Members, Transactions, and Fines instantly.

Role-Based Access Control

Dual specialized dashboards for Administrators/Librarians and Student Patrons with dedicated permission boundaries.
